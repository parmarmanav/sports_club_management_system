# Sports Club Management System

A comprehensive management system for sports clubs, handling everything from member registration to court bookings, pro shop inventory, bar and restaurant POS, and staff scheduling.

## Documentation

This repository contains design and planning documentation for the system:

- **[`ANALYSIS.md`](./ANALYSIS.md)**: Detailed breakdown of the system requirements, scene-by-scene use cases, actors/roles, and module split.
- **[`API.md`](./API.md)**: API endpoint documentation covering various modules (Members, Booking, Shop, Bar, HR, etc.).
- **[`ASSUMPTIONS.md`](./ASSUMPTIONS.md)**: Key technical and business assumptions made during the design phase.
- **[`DEMO_PATH.md`](./DEMO_PATH.md)**: A sequential script/path for demonstrating the core features of the system.

## Database

- **[`schema.sql`](./schema.sql)**: Database schema definitions (tables, relations, constraints).
- **[`seed.sql`](./seed.sql)**: Seed data for initializing the database with sample records.
